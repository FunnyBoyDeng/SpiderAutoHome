# Contributing to SpiderAutoHome

Thank you for your interest in contributing to SpiderAutoHome.

SpiderAutoHome is an educational C#/.NET project originally created in 2018. Maintenance resumed in 2026 with the goal of modernizing the codebase while preserving the educational value of the original examples.

## How to Contribute

Contributions are welcome in areas such as documentation, bug fixes, dependency modernization, tests, CI improvements, and updated examples.

For significant changes, please open an issue first so the proposed approach can be discussed before implementation.

## Development Principles

Please keep contributions focused and reviewable.

Changes should preserve the educational purpose of the project, avoid unnecessary large rewrites, and clearly document any behavior or compatibility changes.

When updating legacy code, please distinguish between:

* fixes to the original .NET Core 2.0 / DotnetSpider 2.5.0 implementation;
* modernization work targeting newer .NET and DotnetSpider versions.

Untested migration work should not be presented as production-ready.

## Pull Requests

Before submitting a pull request:

1. Describe the problem or improvement clearly.
2. Keep the change focused on one purpose where possible.
3. Explain any dependency or compatibility changes.
4. Include testing notes or reproduction steps when applicable.
5. Update relevant documentation when behavior changes.

Pull requests may be updated during review before they are merged.

## Issues

Issues are welcome for:

* bugs;
* documentation problems;
* compatibility issues;
* dependency modernization;
* build or environment problems;
* suggestions for improving the educational examples.

When reporting a problem, please include relevant environment information, error messages, and reproduction steps when possible.

## Responsible Use

This project is intended primarily for educational and research purposes.

Contributors should not add examples or features specifically intended to bypass access controls, authentication protections, anti-abuse systems, rate limits, or other technical restrictions.

Web data extraction examples should respect applicable laws, website terms of service, privacy requirements, robots policies, and data-use restrictions.

## Code of Conduct

Please keep discussions professional, constructive, and focused on improving the project.

Respectful technical disagreement is welcome. Personal attacks, harassment, or abusive behavior are not.
